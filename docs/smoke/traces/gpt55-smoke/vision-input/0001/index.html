Method

For frames 01-19, the script starts from an image-derived background made by lightly inpainting the initially suspended ball and orange block while preserving the wall, pillows, seam, lighting, and overhead tool areas from the first frame. Soft ellipses and blurred overlays create contact shadows and shallow pillow dents as the objects land and settle.
