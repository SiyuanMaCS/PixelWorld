## Generation protocol

The active baseline is `native_v2_100k`:

- one fresh Codex session per case;
- clean case workspace with benchmark input and shared PixelWorld helpers only;
- Text and Vision-Agent tracks;
- no image/video generator, learned simulator, reference continuation, masks,
  scores, memory, other cases, network tools or subagents in the model
  workspace;
- direct RGB tensor/video output;
- externally monitored cumulative 100k reported output-token threshold;
- autonomous checking and revision are allowed, and intermediate candidates are
  recorded as trace evidence rather than hidden retries.

The frozen protocol and reproducibility profile are in
[`baselines/native_v2_100k`](../baselines/native_v2_100k/README.md).

## Score readiness

Generation progress is not the same as an official score.

- Physics-IQ scores are official only after a complete 198-case model/track
  cohort is encoded losslessly and run through the pinned official evaluator.
- RoboJudge scores are official only after all 50 shared tasks are prepared and
  evaluated by the original RoboJudge-9B path. If CUDA is unavailable, the page
  must show that blocker rather than a score.
- VBench-2.0 subset and PhyGenBench pages currently track generation progress
  and galleries. Report them as configured/smoke/full-generation status until
  their official scoring adapters are explicitly run and recorded.

Unknown token usage is not zero. Interrupted requests remain unknown unless an
independent transport-accounting proof records that no model output was sampled.
