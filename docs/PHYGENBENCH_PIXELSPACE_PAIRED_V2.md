# PhyGenBench T2V plus paired I2V protocol v2

PhyGenBench contributes two related PixelWorld conditions:

- the **official T2V** benchmark: 160 original text prompts and official
  PhyGenBench scoring;
- a **PixelWorld I2V extension**: the same prompts paired with selected
  pre-action Qwen-Image-2.1 initial frames.

Earlier pre-v2 VBench and PhyGenBench generation runs are historical artifacts
under `legacy/t2v_pre_pixelspace_v2_20261112/`.

## Question

Can a coding agent produce a physically meaningful **photorealistic RGB video**
directly in pixel space from text, and how much does a high-quality initial
image change that result?

The comparison uses the same original PhyGenBench caption in two conditions:

- **T2V:** caption only; the agent creates every frame. This is the formal
  PhyGenBench benchmark condition.
- **I2V-QwenInit:** the same caption plus a Qwen-Image-2.1 initial frame that
  depicts the pre-action state.  Qwen is used only for this conditioning frame,
  never for the generated video or a later video frame. This is an additional
  PixelWorld paired condition and must be reported separately from the official
  T2V leaderboard.

## Agent-visible method boundary

The task contract says only:

> Construct the video directly in image/pixel space. Do not build a separate
> scene/world model or physics simulation and render it into video. Aim for
> live-action photographic realism for the full scene, with coherent
> appearance and motion.

The ordinary PixelWorld prohibitions remain: no external image/video models,
learned renderers, reference continuations, physics engines, network, or
subagents.  The agent may freely use local Python, NumPy/PIL, masks,
coordinate functions, warps, compositing, texture, lighting, and motion
calculations.  Thus the boundary excludes a conventional 3D/physics pipeline
without prescribing a particular 2D drawing strategy.

Every submitted video is still an explicit `uint8` RGB tensor generated by a
runnable `generate.py`; its first frame is exactly the provided image in I2V.

## Initial-frame construction

Qwen-Image-2.1 is pinned to revision
`d26bb61231c349cf6b7896fa83353113880e1ba3`, at 1024x576 and 40 steps.
For each original PhyGen prompt, three candidates are generated from an
explicit pre-action rewrite.  A selected image must have actual visual-review
evidence and may not depict the outcome, a reference continuation, or a
benchmark answer.  Video generation is independent of candidate selection.

## Smoke before full generation

The smoke uses four visually reviewed Qwen initial states spanning mechanics,
optics, thermal change, and material mixing.  It runs the same model in T2V
Text/Vision and I2V Text/Vision conditions.  The smoke validates artifact
format, first-frame exactness, direct-RGB provenance, and visual plausibility;
it does not itself claim a PhyGenBench official score.

Full generation should run:

- T2V Text and T2V Vision for official PhyGenBench scoring;
- I2V-QwenInit Text and I2V-QwenInit Vision for the paired PixelWorld
  initialization analysis.
